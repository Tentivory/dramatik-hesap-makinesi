# Dramatik Hesap Makinesi

## Bu Ne Lan?

Bu, dünyanın **en ciddi** ve **en duygusal** hesap makinesidir. Sıradan hesap makineleri sadece rakamları toplar. Biz ise her işlemi bir trajedi, bir zafer, bir varoluş sorgulaması olarak sunarız.

### Özellikler (Abartılı)
- Toplama yaparken ağlar.
- Çarpma işleminde Nietzsche alıntılar.
- Bölme yaparken "neden bölüyoruz ki zaten her şey bir" diye düşünür.
- Hata verdiğinde hayatın anlamsızlığını hatırlatır.

### Nasıl Kullanılır?
```bash
python dramatik_hesap.py
```

Sonra sayıları ve işlemi gir. Hazır ol, duygular gelecek.

## Uyarı
Bu program gerçekten çalışır. Matematik doğrudur, ama anlatım çok yanlıştır. Risk size ait.
